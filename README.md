## Publish
1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the contents of this package to the repository root.
3. GitHub → Settings → Pages → deploy from `main` branch / root.
4. Replace every `YOUR-GITHUB-USERNAME` placeholder with the real username.
5. When a custom domain is purchased, add it in GitHub Pages settings and update canonical/sitemap URLs.

## Before monetization
Publish substantial original articles and real projects first. Add affiliate disclosures and privacy/cookie information where applicable. Monetization and search rankings are not guaranteed and depend on content quality, search demand, authority, policies and time.

## Security
Never publish passwords, API keys, access tokens, QID/passport information, private client data, company-confidential records or lab credentials.
